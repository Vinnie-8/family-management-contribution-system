# Family Contribution Management System

**Welcome to the project documentation for the Family Contribution Management System — a platform for digitizing how families manage meetings, contributions, pledges, and payments.**

## What this project does

!!! note
    This system replaces manual record-keeping (notebooks, spreadsheets, WhatsApp chaos) with a single, transparent, auditable source of truth — while preserving traditional family governance roles: Chairman, Secretary, and Treasurer.

## Key features
- Fixed (AGM-style) and voluntary (pledge-based) contribution campaigns
- M-Pesa mobile money integration and manual payment tracking
- Support for phoneless members via Guardian/Proxy accounts
- A permanent, tamper-proof audit trail
- Meeting management with attendance and minutes
